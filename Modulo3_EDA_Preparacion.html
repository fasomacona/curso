Módulo 3

Preparación y Análisis Exploratorio de Datos

Duración: 6 horas

Objetivos del Módulo

  • Cargar datos desde diferentes fuentes de forma eficiente.
  • Realizar una limpieza de datos profesional y documentada.
  • Ejecutar un Análisis Exploratorio de Datos (EDA) completo.
  • Crear visualizaciones claras y orientadas a insights de negocio.
  • Aplicar feature engineering básico dentro de un proyecto.

Contenido Detallado

1. Carga de Datos (1 h)

  • Lectura de CSV, Excel, JSON y bases de datos
  • Opciones importantes de pandas (parse_dates, dtype, na_values)
  • Inspección inicial: shape, dtypes, head, info, describe
import pandas as pd

df = pd.read_csv("datos.csv", parse_dates=["fecha"])
print(df.shape)
df.info()
df.describe()

2. Limpieza de Datos (1.5 h)

  • Detección y tratamiento de valores nulos
  • Eliminación o corrección de duplicados
  • Manejo de outliers
  • Conversión de tipos de datos
  • Normalización de texto y categorías
# Valores nulos
df.isnull().sum()
df = df.dropna(subset=["columna_importante"])
df["edad"] = df["edad"].fillna(df["edad"].median())

# Duplicados
df = df.drop_duplicates()

3. Análisis Exploratorio de Datos – EDA (1.5 h)

  • Análisis univariado y bivariado
  • Correlaciones y matrices de correlación
  • Agrupaciones y tablas dinámicas
  • Detección de patrones y anomalías
df.groupby("categoria")["ventas"].agg(["mean", "sum", "count"])
pd.crosstab(df["region"], df["producto"])

4. Visualización Profesional (1.5 h)

  • Matplotlib y Seaborn: gráficos de barras, líneas, histogramas, boxplots
  • Heatmaps y pairplots
  • Buenas prácticas de visualización (títulos, etiquetas, colores, accesibilidad)
import matplotlib.pyplot as plt
import seaborn as sns

plt.figure(figsize=(10,6))
sns.barplot(data=df, x="region", y="ventas", estimator="mean")
plt.title("Ventas promedio por región")
plt.show()

5. Feature Engineering Básico (0.5 h)

  • Creación de variables temporales (año, mes, día de la semana)
  • Transformaciones simples y variables derivadas
  • Codificación de variables categóricas (introducción)

Actividades Prácticas

  • Cargar un dataset real o semirreal y realizar la limpieza completa.
  • Elaborar un EDA documentado con al menos 8 visualizaciones.
  • Extraer 5 insights de negocio claros a partir del análisis.
  • Crear variables nuevas útiles para un posible modelado posterior.
