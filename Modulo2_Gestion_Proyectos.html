Módulo 2

Gestión de Proyectos de Ciencia de Datos

Duración: 6 horas

Objetivos del Módulo

  • Comprender el ciclo de vida completo de un proyecto de ciencia de datos.
  • Aplicar la metodología CRISP-DM de forma práctica.
  • Conocer cómo adaptar Agile/Scrum a proyectos de datos.
  • Identificar roles y responsabilidades en un equipo de datos.
  • Usar Git y GitHub para control de versiones y colaboración.
  • Documentar proyectos de forma profesional y reproducible.

Contenido Detallado

1. Ciclo de Vida de un Proyecto de Datos (1 h)

  • De la idea de negocio al valor entregado
  • Diferencias entre proyectos de software y proyectos de datos
  • Principales causas de fracaso en proyectos de ciencia de datos

2. Metodología CRISP-DM (1.5 h)

Las 6 fases de CRISP-DM:

FaseObjetivo principal
Business UnderstandingEntender el problema de negocio y objetivos
Data UnderstandingExplorar y conocer los datos disponibles
Data PreparationLimpiar, transformar y preparar los datos
ModelingConstruir y entrenar modelos
EvaluationEvaluar resultados desde el punto de vista de negocio
DeploymentPoner el modelo en producción o entregar resultados

3. Agile y Scrum en Proyectos de Datos (1 h)

  • Sprints, product backlog y daily stand-ups adaptados a datos
  • Definición de “Done” en un proyecto de ciencia de datos
  • Priorización de hipótesis y experimentos

4. Roles en un Equipo de Datos (0.75 h)

  • Data Scientist, Data Analyst, Data Engineer, ML Engineer
  • Product Owner / Stakeholder de negocio
  • Comunicación efectiva entre perfiles técnicos y de negocio

5. Git, GitHub y Reproducibilidad (1.25 h)

  • Comandos esenciales de Git (init, add, commit, push, pull, branch)
  • Estructura recomendada de repositorio de proyecto de datos
  • README.md, requirements.txt / environment.yml
  • Notebooks limpios y reproducibles
git init
git add .
git commit -m "Inicio del proyecto de ciencia de datos"
git remote add origin https://github.com/usuario/proyecto.git
git push -u origin main

6. Documentación y Entregables (0.5 h)

  • Qué documentar y para quién
  • Reportes ejecutivos vs documentación técnica
  • Plantillas de documentación de proyectos

Actividades Prácticas

  • Definir el problema de negocio de un caso de estudio usando CRISP-DM.
  • Crear un repositorio en GitHub con la estructura profesional de un proyecto de datos.
  • Redactar un README claro y un archivo de dependencias.
  • Simular un sprint planning de un proyecto de ciencia de datos.
