Módulo 1

Fundamentos de Python y Entorno de Trabajo

Duración: 6 horas

Objetivos del Módulo

  • Configurar un entorno profesional de trabajo con Python y Jupyter.
  • Dominar la sintaxis fundamental de Python de forma rápida y práctica.
  • Manejar estructuras de datos esenciales para ciencia de datos.
  • Escribir funciones y código limpio y reutilizable.
  • Introducirse a NumPy como base para el análisis numérico.

Contenido Detallado

1. Configuración del Entorno (1 h)

  • Instalación de Anaconda o Miniconda
  • Creación y activación de entornos virtuales
  • Instalación de Jupyter Lab / Notebook
  • Buenas prácticas de organización de carpetas de proyecto
conda create -n ciencia-datos python=3.11 -y
conda activate ciencia-datos
pip install jupyterlab numpy pandas matplotlib seaborn

2. Sintaxis Básica de Python (1.5 h)

  • Variables, tipos de datos y operadores
  • Estructuras de control: if, for, while
  • Manejo de errores con try/except
# Ejemplo de control de flujo
edad = 28
if edad >= 18:
    print("Adulto")
else:
    print("Menor de edad")

for i in range(5):
    print(i)

3. Estructuras de Datos (1.5 h)

  • Listas, tuplas, diccionarios y sets
  • Métodos más utilizados
  • Comprensión de listas (list comprehensions)
ventas = [1200, 1500, 980, 2100]
promedio = sum(ventas) / len(ventas)

# Comprensión de listas
cuadrados = [x**2 for x in range(10)]

4. Funciones y Modularidad (1 h)

  • Definición de funciones
  • Parámetros, argumentos y valores de retorno
  • Alcance de variables (scope)
  • Módulos y paquetes básicos
def calcular_estadisticas(lista):
    return {
        "media": sum(lista)/len(lista),
        "min": min(lista),
        "max": max(lista)
    }

5. Introducción a NumPy (1 h)

  • Arrays vs listas de Python
  • Creación y operaciones vectorizadas
  • Indexación y slicing
  • Operaciones estadísticas básicas
import numpy as np

arr = np.array([10, 20, 30, 40, 50])
print(arr.mean(), arr.std())

Actividades Prácticas

  • Crear un entorno limpio e instalar todas las librerías del curso.
  • Escribir un notebook con ejercicios de sintaxis y estructuras de datos.
  • Implementar funciones para calcular estadísticas descriptivas básicas.
  • Practicar operaciones con NumPy sobre datos numéricos.
